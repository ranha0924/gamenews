# gamenews

## 생애주기 자산배분 경제 게임 (`index.html`)

브라우저로 `index.html`을 열면 바로 실행됩니다. (`assets/`, `fonts/` 폴더가 같은 위치에 있어야 그림과 글꼴이 보입니다.)

- 시작 튜토리얼: 페이지를 열면 게임 전에 4쪽짜리 안내창(게임 소개 → 한 턴의 4단계 → 예금·주식·채권 → 상자와 결과 보기)이 뜸. 건너뛰기 가능하고, 진행 방법 창의 [튜토리얼 다시 보기]로 다시 열 수 있음. 문구는 `index.html`의 `TUTORIAL` 배열에서 수정
- 턴마다 4단계로 진행하며, 끝낸 단계는 되돌릴 수 없음
  1. **1단계 지출과 선택** → 선택 완료: 선택 결과(이익/손실), 연봉 변화, 필수·선택에 따른 금액 변화 설명 공개
     - **대출** → 1단계 아래 대출 창에서 필요한 만큼 빌린 뒤 [대출 완료] (빌리지 않아도 눌러야 2단계가 열림)
  2. **2단계 자산 배분** → 투자 가능 금액(1단계 여유 자금 + 대출)을 예금·주식·채권 비율로 확정 (숫자 직접 입력 또는 -/+ 버튼으로 5%p씩). 2턴부터는 지난 턴에 확정한 비율에서 시작하고, 종목마다 ±10%p까지만 바꿀 수 있음 (`ALLOC_LIMIT`에서 수정)
  3. **3단계 경제 시나리오** → 선생님이 그 턴의 상자를 열어 주면, 상자 번호(1~5)를 열어 시나리오 내용과 투자 결과 공개 (최종 완료 전까지 다른 상자로 바꿀 수 있음. 아래 '선생님 스위치' 참고)
  4. **4단계 최종 완료** → 투자 결과, '왜 이렇게 나왔을까?' 해설, 이월 자금 공개 후 상단의 다음 턴 칸 강조
- 선택 사항의 금액과 이익/손실 여부는 **선택 완료 전까지 비공개**
- 1턴에서 가정 형태(맞벌이/외벌이)를 고르면 3턴까지 유지, 2턴에는 둘째 출산 선택지(국가 지원금 포함)
- 외벌이는 1~3턴에 부업 선택 가능(맞벌이는 선택 불가)
- 주사위가 그려진 운 선택지(턴마다 1개: 1턴 스타트업, 2턴 고수익 투자, 3턴 프랜차이즈, 4턴 노후 대비 상가)는 거는 돈(5,000만~1억 5,000만 원, 1,000만 원 단위)을 정함: 1억이면 5:5, 1,000만 원마다 성공/실패 확률 ±5%p(화면에는 확률 미표시), 결과 금액은 거는 돈에 비례하고 성공하면 건 돈 이상 수익
- 스타트업 진로: 1턴에 스타트업으로 이직하면(성공·실패 상관없이) 2~4턴마다 '스타트업 계속 다니기'(1턴과 같은 운 대결) 또는 '회사에 취직하기'(지금 연봉 그대로) 중 하나를 꼭 골라야 함. 한 번 취직하면 다음 턴부터는 진로 선택이 사라짐 (`startupStay`, `startupQuit` 객체에서 수정)
- 대출: 1단계 바로 아래 대출 창에서, 1단계 선택 완료 후부터 [대출 완료]를 누르기 전까지 받을 수 있음(선택 완료 전에는 잠김, 여러 번 가능, 턴마다 한도 3억 원, 1,000만 원 단위). [대출 완료]를 누르면 그 턴에는 더 빌릴 수 없고, 빌린 돈은 모두 2단계 투자 가능 금액에 더해져 투자됨. 금리 = 직전 턴에 뽑은 시나리오의 예금금리 그대로(1턴은 기본 3%), 이자는 턴 전체에 한 번 적용하고 턴이 끝나면 원금과 이자를 한꺼번에 상환 (`LOAN` 객체에서 수정)
- 내 돈은 마이너스(빚)가 될 수 있고, 빚은 다음 턴으로 이월됨
- 다음 턴은 상단 칸(강조 표시)을 눌러 이동. 끝낸 턴은 값을 바꿀 수 없고, 4턴을 모두 마치기 전에는 지난 턴 화면으로 돌아갈 수도 없음 (4턴을 마치면 모든 턴을 다시 볼 수 있음)
- 일반 선택지(운 선택지 제외)는 비용이 들지만 반드시 그보다 큰 이익(수익 또는 연봉 상승)이 생김. 연봉 상승의 이익은 64세까지 늘어나는 소득(예상)으로 계산
- 부업(외벌이 전용)과 임원 승진은 지금처럼 정해 둔 확률로 성공·실패가 갈림
- 선택지 화면에는 드는 돈(금액)과 좋아지는 점(▲ 빨강)·나빠질 수 있는 점(▼ 파랑)을 보여 주고, 실제 결과와 금액은 선택 완료 후 공개. 문구는 선택지의 `pay`, `good`, `bad` 필드에서 수정
- 선택지 내용·확률·금액은 `index.html`의 `choices` 객체, 시나리오는 `scenarios` 객체에서 수정
- '왜 이렇게 나왔을까?' 해설은 [흥덕 뉴스](https://newsgame-eight.vercel.app/)(저장소 `ranha0924/newsgame`)의 같은 번호 시나리오 기사·해설을 옮겨 온 것으로, `scenarioNews` 객체에 있습니다. 신문 내용을 바꾸면 이 객체도 함께 고쳐 주세요. '시나리오 N 신문 보러 가기' 버튼은 신문 사이트 주소에 `#scenario-N`을 붙여 같은 번호의 탭을 바로 엽니다 (신문 사이트에서 이 주소를 지원해야 함).

## 선생님 스위치 (3단계 상자 열기)

학생은 선생님이 그 턴을 열어 줘야 3단계 상자(1~5)를 고를 수 있습니다.

- **학생 화면**: 3단계에 들어서면 상자가 잠겨 있고 '선생님이 상자를 열어 줄 때까지 기다려요'가 보입니다. 3단계에 있는 동안 4초마다 서버에 확인하고, 선생님이 열면 새로 고침 없이 저절로 열립니다.
- **선생님 화면**: 게임 주소 끝에 `?teacher`를 붙여 엽니다 (예: `https://게임주소/?teacher`). 비밀번호를 넣으면 턴마다 [열기] / [잠그기] 버튼과 [모두 잠그기 (다음 반 수업 준비)] 버튼이 나옵니다. 그 탭을 닫기 전까지는 비밀번호를 다시 묻지 않습니다.
- 열었다가 다시 잠그면 학생은 상자를 고르거나 바꿀 수 없습니다. 이미 고른 학생은 그 상자로 최종 완료할 수 있습니다.
- 스위치는 하나라서 모든 학생이 같은 스위치를 봅니다. 다음 반 수업 전에 [모두 잠그기]를 누르세요. 여러 반이 **같은 시간에** 하면 반마다 따로 열 수는 없습니다.
- 서버 저장소가 연결되지 않았거나 `index.html`을 파일로 직접 열면, 잠금 없이 예전처럼 바로 상자를 고를 수 있습니다.
- 수업용 잠금이라 개발자 도구를 다룰 줄 아는 학생이 억지로 여는 것까지 막지는 못합니다.
- 서버 코드는 `api/gate.js`, 확인 간격은 `index.html`의 `GATE.pollMs`(밀리초)에서 바꿉니다.

### 처음 한 번 설정 (Vercel)

1. Vercel 대시보드에서 `gamenews` 프로젝트를 열고 **Storage** 탭에서 Upstash의 **Redis**(무료 플랜)를 만들어 이 프로젝트에 연결합니다. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경 변수가 자동으로 생깁니다.
2. **Settings → Environment Variables**에 `TEACHER_PASSWORD`를 추가하고 값에 선생님 비밀번호를 넣습니다. 비밀번호는 코드가 아니라 Vercel에만 저장되므로 학생이 페이지 소스를 봐도 알 수 없습니다.
3. **Deployments**에서 최신 배포를 **Redeploy** 합니다. 환경 변수는 다시 배포해야 적용됩니다.
4. `https://게임주소/?teacher`를 열고 비밀번호를 넣은 뒤 [열기] / [잠그기]가 되는지 확인합니다.

브랜치 미리보기(Preview) 주소에서도 쓰려면 1~2단계의 환경 변수를 Preview 환경에도 넣어야 합니다.

## 화면 디자인

16비트 도트 RPG 인생 시뮬레이션 스타일입니다.

- 한 턴은 인생의 하루 중 한때입니다. 같은 거리가 1턴 아침 → 2턴 낮 → 3턴 오후 → 4턴 노을 → 최종 결과 밤으로 바뀌고, 캐릭터도 25·35·45·55·64세로 나이가 듭니다.
- 이익·오름은 빨강, 손실·내림·빚은 파랑입니다 (국내 증권 앱과 같은 방식).
- 턴별 시기 이름, 거리 시간대, 캐릭터 나이, 1턴 자산 배분 기본값은 `index.html`의 `VIEW` 객체에 있습니다.
- `assets/`의 도트 그림(캐릭터, 초상, 거리 배경, 예금·주식·채권 건물, 보물상자, 주사위, 아이콘)은 Higgsfield로 만든 뒤 원래 픽셀 크기로 줄인 PNG입니다. 그림을 바꾸면 `SPRITE_SIZE`의 크기도 함께 고쳐 주세요. 화면에는 이 크기의 정수배로 그려야 픽셀이 고르게 보입니다.
- `fonts/`의 도트 글꼴은 [갈무리(Galmuri)](https://github.com/quiple/galmuri)이며 SIL Open Font License 1.1(`fonts/OFL.txt`)을 따릅니다. 긴 해설은 읽기 쉽도록 기기 기본 글꼴로 표시합니다.

## Vercel 배포

빌드 과정이 없는 정적 사이트에, 선생님 스위치용 서버 함수 하나(`api/gate.js`, 주소 `/api/gate`)가 붙어 있습니다. `vercel.json`에서 Framework Preset을 "Other"(`"framework": null`)로 고정해 두었으므로, 저장소 루트의 `index.html`이 그대로 서비스되고 `api/` 폴더의 파일은 Vercel이 서버 함수로 실행합니다. 선생님 스위치 설정은 위의 '처음 한 번 설정'을 따르세요.

1. [vercel.com/new](https://vercel.com/new)에서 GitHub 저장소 `ranha0924/gamenews`를 Import
2. 설정은 그대로 두고 **Deploy**
3. 이후 `main` 브랜치에 push하면 자동으로 재배포되고, 다른 브랜치는 미리보기(Preview) 주소로 배포됩니다.
