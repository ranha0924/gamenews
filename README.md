# gamenews

## 생애주기 자산배분 경제 게임 (`index.html`)

브라우저로 `index.html`을 열면 바로 실행됩니다.

- 턴마다 4단계로 진행하며, 끝낸 단계는 되돌릴 수 없음
  1. **STEP 1 지출과 선택** → 선택 완료: 선택 결과(이익/손실), 연봉 변화, 필수·선택에 따른 금액 변화 설명 공개
  2. **STEP 2 자산 배분** → 예금·주식·채권 비율 확정
  3. **STEP 3 경제 시나리오** → 번호(1~5)로 고르면 시나리오 내용과 투자 결과 공개 (최종 완료 전까지 다시 고를 수 있음)
  4. **STEP 4 최종 완료** → 투자 결과, '왜 이렇게 나왔을까?' 해설, 이월 자금 공개 후 상단의 다음 턴 탭 강조
- 선택 사항의 금액과 이익/손실 여부는 **선택 완료 전까지 비공개**
- 1턴에서 가정 형태(맞벌이/외벌이)를 고르면 3턴까지 유지, 2턴에는 둘째 출산 선택지(국가 지원금 포함)
- 외벌이는 1~3턴에 부업 선택 가능(맞벌이는 선택 불가)
- 🎲 운 선택지(턴마다 1개: 1턴 스타트업, 2턴 고수익 투자, 3턴 프랜차이즈, 4턴 노후 대비 상가)는 거는 돈(5,000만~1억 5,000만 원, 1,000만 원 단위)을 정함: 1억이면 5:5, 1,000만 원마다 성공/실패 확률 ±5%p(화면에는 확률 미표시), 결과 금액은 거는 돈에 비례하고 성공하면 건 돈 이상 수익
- 🏦 대출: 턴 맨 위 대출 칸에서 단계와 상관없이 언제든 받을 수 있음(여러 번 가능, 턴마다 한도 3억 원, 1,000만 원 단위). 자산 배분 확정 전에 빌린 돈은 투자되고, 확정 후에 빌린 돈은 현금으로 보관. 금리 = 직전 턴 시나리오 금리 + 가산금리 2%p(1턴은 기본 3% + 2%p), 이자는 턴 전체에 한 번 적용하고 턴이 끝나면 원금과 이자를 한꺼번에 상환 (`LOAN` 객체에서 수정)
- 내 돈은 마이너스(빚)가 될 수 있고, 빚은 다음 턴으로 이월됨
- 다음 턴은 상단 탭(강조 표시)을 눌러 이동
- 일반 선택지(🎲 운 요소 제외)는 비용이 들지만 반드시 그보다 큰 이익(수익 또는 연봉 상승)이 생김. 연봉 상승의 이익은 64세까지 늘어나는 소득(예상)으로 계산
- 부업(외벌이 전용)과 임원 승진은 지금처럼 정해 둔 확률로 성공·실패가 갈림
- 선택지 내용·확률·금액은 `index.html`의 `choices` 객체, 시나리오는 `scenarios` 객체에서 수정
- '왜 이렇게 나왔을까?' 해설은 [흥덕 뉴스](https://newsgame-eight.vercel.app/)(저장소 `ranha0924/newsgame`)의 같은 번호 시나리오 기사·해설을 옮겨 온 것으로, `scenarioNews` 객체에 있습니다. 신문 내용을 바꾸면 이 객체도 함께 고쳐 주세요.

## Vercel 배포

빌드 과정이 없는 정적 사이트입니다. `vercel.json`에서 Framework Preset을 "Other"(`"framework": null`)로 고정해 두었으므로, 저장소 루트의 `index.html`이 그대로 서비스됩니다.

1. [vercel.com/new](https://vercel.com/new)에서 GitHub 저장소 `ranha0924/gamenews`를 Import
2. 설정은 그대로 두고 **Deploy**
3. 이후 `main` 브랜치에 push하면 자동으로 재배포되고, 다른 브랜치는 미리보기(Preview) 주소로 배포됩니다.
